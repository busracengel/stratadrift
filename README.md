# StrataDrift

Open Geoscience Resources.

A GitHub Pages website for organizing geology lecture notes, research papers, maps, datasets, field resources and useful tools.

## Local preview

Open `index.html` in a browser.

## GitHub Pages

Repository: `busracengel/stratadrift`

After pushing the files:
1. GitHub → Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main`
4. Folder: `/ (root)`
5. Save

The site should become available at:

`https://busracengel.github.io/stratadrift/`
